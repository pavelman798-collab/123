## 📖 Описание

Система предназначена для распознавания и категоризации ответов клиентов на приветственную фразу голосового ассистента:

> **"Привет. Меня зовут Лиза - я голосовой помощник"**

### Особенности

✅ **Использование корней слов** - паттерны учитывают различные словоформы и склонения
✅ **Поддержка множественных категорий** - одна фраза может относиться к нескольким типам
✅ **Case-insensitive** - регистронезависимое распознавание
✅ **12 категорий ответов** - от приветствий до отказов
✅ **Groovy regex** - нативная поддержка регулярных выражений в Groovy

### Принцип работы

```groovy
Входной текст → Регулярные выражения → Категория(-ии) → Логика ответа
```

**Пример:**
```
"Привет! Что ты умеешь?"
  → GREETINGS + CAPABILITY_QUESTIONS
  → [greeting, capability_question]
  → Ответ: приветствие + описание возможностей
```

## 📂 Категории паттернов

### 1. 👋 GREETINGS - Приветствия

**Примеры:** привет, здравствуй, добрый день, хай, алло

```groovy
~/(?i).*\b(привет|приветик|приветствую|приветики)\b.*/
~/(?i).*\b(здравству|здорово|здрасьте|здрасти)\w*\b.*/
~/(?i).*\b(добр\w*)\s+(день|утро|вечер|ночь)\b.*/
```

**Распознаёт:**
- Привет / Приветик / Приветствую
- Здравствуй / Здравствуйте / Здрасьте
- Добрый день / Доброе утро / Добрый вечер
- Хай / Хелло / Алло

---

### 2. 🙏 POLITE_RESPONSES - Вежливые ответы

**Примеры:** спасибо, рад слышать, приятно познакомиться

```groovy
~/(?i).*\b(приятн\w*)\s*(познаком\w*|слышать|видеть)?\b.*/
~/(?i).*\b(рад|рада|радо|рады)\b.*(слышать|познаком\w*|вас|тебя|вами)?.*/
~/(?i).*\b(спасиб\w*|благодар\w*|признател\w*)\b.*/
```

**Распознаёт:**
- Спасибо / Благодарю
- Рад слышать / Рада познакомиться
- Приятно познакомиться / Очень приятно
- Хорошо / Отлично / Замечательно

---

### 3. ✅ CONFIRMATIONS - Подтверждения

**Примеры:** да, слушаю, понял, давай

```groovy
~/(?i)^\s*(да|ага|угу|ок|окей|ладно)\s*$/
~/(?i).*\b(слуша\w*|слышу)\b.*/
~/(?i).*\b(понял|поняла|поняли|понятн\w*|ясно|понял\w*)\b.*/
```

**Распознаёт:**
- Да / Ага / Угу / Ок
- Слушаю / Слышу
- Понял / Поняла / Понятно
- Давай / Вперед / Продолжай

---

### 4. 🤔 CAPABILITY_QUESTIONS - Вопросы о возможностях

**Примеры:** что ты умеешь, чем можешь помочь

```groovy
~/(?i).*\b(что|а\s+что)\s+(ты|вы)\s+(умее\w*|може\w*|делае\w*)\b.*/
~/(?i).*\b(чем|в\s+чем|как)\s+(може\w*|помог\w*|помоч\w*|помощ\w*)\b.*/
```

**Распознаёт:**
- Что ты умеешь? / Что можешь делать?
- Чем можешь помочь?
- Какие у тебя функции?
- Зачем ты нужна?

---

### 5. 💬 SMALL_TALK - Светская беседа

**Примеры:** как дела, как настроение

```groovy
~/(?i).*\b(как)\s+(дела|у\s+(тебя|вас)|ты|вы|сам\w*|настроен\w*|поживае\w*)\b.*/
~/(?i).*\b(что|как)\s+(нов\w*|жизнь|житье)\b.*/
```

**Распознаёт:**
- Как дела? / Как ты?
- Что нового? / Как жизнь?
- Все хорошо? / Как настроение?

---

### 6. 🆔 IDENTITY_QUESTIONS - Вопросы идентификации

**Примеры:** кто ты, представься, как тебя зовут

```groovy
~/(?i).*\b(кто)\s+(ты|вы|это|говор\w*|звон\w*)\b.*/
~/(?i).*\b(представ\w*|назов\w*|скажи\w*)\s+(себя|имя|как\s+зовут)\b.*/
```

**Распознаёт:**
- Кто ты? / Кто говорит?
- Представься / Назови себя
- Как тебя зовут?
- Кто ты такая?

---

### 7. ❓ PURPOSE_QUESTIONS - Вопросы о цели звонка

**Примеры:** зачем звонишь, что нужно

```groovy
~/(?i).*\b(зачем|почему|по\s+как\w*\s+причин\w*)\s+(звон\w*|звоним\w*)\b.*/
~/(?i).*\b(что|чего)\s+(нужн\w*|надо|хоти\w*|треб\w*)\b.*/
```

**Распознаёт:**
- Зачем звонишь? / Почему звонишь?
- Что нужно? / Что хотите?
- По какому вопросу?
- В чем дело?

---

### 8. ❌ REJECTIONS - Отказы

**Примеры:** не нужно, отстань, пока

```groovy
~/(?i).*\b(отстань|отвали|уйди|отъебись|свали|отвян\w*)\b.*/
~/(?i).*\b(не\s+(нужн\w*|надо|хочу|интересн\w*|требуется))\b.*/
~/(?i).*\b(до\s+свидан\w*|всего\s+добр\w*|прощай\w*|пока)\b.*/
```

**Распознаёт:**
- Не нужно / Не интересно
- Отстань / Отвали
- Пока / До свидания
- Не звони больше

---

### 9. 🔄 CLARIFICATIONS - Переспрос

**Примеры:** что, не расслышал, повтори

```groovy
~/(?i)^\s*(что|чего|а|ась|га|чё|чево)\s*\??\s*$/
~/(?i).*\b(не\s+(расслыша\w*|слыш\w*|понял\w*))\b.*/
~/(?i).*\b(повтор\w*|еще\s+раз|можно\s+еще|что\s+сказал\w*)\b.*/
```

**Распознаёт:**
- Что? / А? / Чего?
- Не расслышал / Не слышу
- Повтори / Еще раз
- Плохо слышно

---

### 10. ⏳ WAIT_REQUESTS - Просьбы подождать

**Примеры:** секунду, минутку, сейчас

```groovy
~/(?i).*\b(секунд\w*|минут\w*|момент|мгновени\w*)\b.*/
~/(?i).*\b(сейчас|щас|счас|погод\w*|подожд\w*)\b.*/
```

**Распознаёт:**
- Секунду / Минутку
- Сейчас / Щас
- Подожди / Погоди

---

### 11. 🚫 BUSY_RESPONSES - Занят

**Примеры:** я занят, не могу говорить, перезвоните

```groovy
~/(?i).*\b(я|сейчас)\s+(занят|занята|занято|занят\w*)\b.*/
~/(?i).*\b(не\s+могу|нельзя|некогда)\s+(говор\w*|разговар\w*|общ\w*)\b.*/
~/(?i).*\b(перезвон\w*|позвон\w*|звони\w*)\s+(позже|потом|попозже)\b.*/
```

**Распознаёт:**
- Я занят / Занята
- Не могу говорить
- Перезвоните позже
- Я за рулем / Я на работе

---

### 12. 🤖 BOT_QUESTIONS - Вопросы о роботе

**Примеры:** ты робот, ты бот, живой человек

```groovy
~/(?i).*\b(ты|вы)\s+(робот|бот|машин\w*|компьютер|автомат)\b.*/
~/(?i).*\b(это)\s+(автоответч\w*|запись|автомат\w*|робот)\b.*/
~/(?i).*\b(живой|настоящ\w*|реальн\w*)\s+(человек|собеседн\w*)\b.*/
```

**Распознаёт:**
- Ты робот? / Ты бот?
- Это автоответчик?
- Живой человек?
- С кем я говорю?

## 🚀 Использование

### Базовое использование

```groovy
// Загрузка класса
import VoiceAssistantPatterns

// Получить основную категорию
def userResponse = "Привет, Лиза!"
def category = VoiceAssistantPatterns.categorize(userResponse)
println category  // "greeting"

// Получить все категории
def response2 = "Привет! Что ты умеешь?"
def categories = VoiceAssistantPatterns.categorizeAll(response2)
println categories  // ["greeting", "capability_question"]

// Проверить конкретную категорию
if (VoiceAssistantPatterns.matches(userResponse, VoiceAssistantPatterns.GREETINGS)) {
    println "Клиент поздоровался"
}
```

### Примеры в диалоговом сценарии

```groovy
def handleUserResponse(String userText) {
    def categories = VoiceAssistantPatterns.categorizeAll(userText)

    if ('rejection' in categories) {
        // Клиент отказался
        return "Понял вас. Всего доброго!"

    } else if ('busy' in categories) {
        // Клиент занят
        return "Извините за беспокойство. Перезвоним позже."

    } else if ('greeting' in categories && 'capability_question' in categories) {
        // Клиент поздоровался и спросил о возможностях
        return "Рада знакомству! Я могу помочь вам с записью на прием, проверкой статуса заказа или ответить на вопросы о наших услугах."

    } else if ('greeting' in categories) {
        // Просто поздоровался
        return "Рада слышать! Могу я рассказать, чем могу помочь?"

    } else if ('clarification' in categories) {
        // Не расслышал
        return "Повторяю: меня зовут Лиза, я голосовой помощник. Я могу помочь вам с..."

    } else if ('wait' in categories) {
        // Просит подождать
        return "Конечно, я жду."

    } else {
        // Неопределенный ответ
        return "Понимаю. Могу я рассказать о своих возможностях?"
    }
}

// Примеры
println handleUserResponse("Привет! Что ты умеешь?")
// → "Рада знакомству! Я могу помочь вам с записью на прием..."

println handleUserResponse("Не нужно")
// → "Понял вас. Всего доброго!"

println handleUserResponse("Секунду")
// → "Конечно, я жду."
```

### Оптимизация

1. **Ранний выход:** Метод `categorize()` возвращает первую найденную категорию

## 📝 Примечания

### Особенности распознавания речи

- **Опечатки STT:** Системы распознавания речи могут допускать ошибки
- **Шум на линии:** Может влиять на качество распознавания
- **Диалекты:** Региональные особенности произношения

**Рекомендация:** Использовать пороговое значение уверенности (confidence threshold) от STT-системы перед применением паттернов.

### Корни слов vs точное совпадение

**Преимущества подхода с корнями:**
- Учитывает все словоформы (слушаю, слушает, слушал)
- Меньше паттернов = быстрее работа
- Гибкость при разговорной речи

**Недостатки:**
- Потенциально больше ложных срабатываний
- Требует тщательного тестирования
