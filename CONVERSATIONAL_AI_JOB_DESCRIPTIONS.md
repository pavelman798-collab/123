## 1. ЛИНГВИСТ-РАЗРАБОТЧИК ГОЛОСОВЫХ СЦЕНАРИЕВ

### 1.1. Общие положения

**Должность:** Лингвист-разработчик голосовых сценариев
**Подразделение:** Центр Conversational AI, МТС Банк
**Подчиняется:** Старшему лингвисту-разработчику голосовых сценариев / Руководителю направления голосовых помощников
**Категория:** Специалист

### 1.2. Цель должности

Разработка, поддержка и оптимизация голосовых сценариев для автоматизации клиентских обращений через голосовой канал МТС Банка с целью повышения качества клиентского обслуживания и снижения операционных затрат.

### 1.3. Функциональные обязанности

**Проектирование диалогов:**
- Разработка логики диалоговых сценариев для голосового канала (IVR, голосовой помощник)
- Создание flowchart диалогов с учетом customer journey
- Проектирование error handling и fallback стратегий
- Разработка промптов и реплик голосового ассистента
- Создание вариативности фраз для естественности диалога

**Настройка интентов и энтитетов:**
- Создание и настройка интентов (намерений пользователя) в NLU-платформе
- Разработка тренировочных фраз для распознавания интентов
- Настройка сущностей (entities) для извлечения ключевой информации
- Тестирование и валидация распознавания интентов
- Создание слотов для сбора необходимой информации от пользователя

**Анализ диалогов:**
- Прослушивание записей реальных диалогов клиентов с голосовым ассистентом
- Анализ логов и транскриптов диалогов
- Выявление проблемных мест и точек отказа (drop-off points)
- Анализ причин непонимания (no-match, low-confidence scenarios)
- Подготовка рекомендаций по улучшению сценариев

**Оптимизация сценариев:**
- Итеративное улучшение формулировок на основе данных
- A/B тестирование различных вариантов промптов
- Оптимизация длины реплик для комфортного восприятия
- Сокращение количества шагов в диалоге
- Повышение показателей успешности диалогов (automation rate, containment rate)

**Работа с ASR/TTS:**
- Подготовка словарей произношений для нестандартных терминов
- Тестирование качества синтеза речи (TTS)
- Настройка SSML тегов для управления интонацией и паузами
- Валидация корректности распознавания речи (ASR) для банковских терминов

**Документирование:**
- Ведение документации по диалоговым сценариям
- Создание спецификаций для разработчиков
- Документирование изменений и версионирование
- Подготовка инструкций для service desk
- Описание логики работы сценариев для стейкхолдеров

**Кросс-функциональное взаимодействие:**
- Работа с аналитиками для определения требований
- Взаимодействие с разработчиками по техническим вопросам интеграции
- Коммуникация с представителями бизнеса для уточнения процессов
- Участие в planning и retrospective сессиях команды

### 1.4. Требования к квалификации

**Образование:**
- Высшее образование: лингвистика, прикладная/компьютерная лингвистика, филология
- Приветствуется дополнительное образование в области UX/UI дизайна, Computer Science

**Опыт работы:**
- Опыт работы от 1 года в разработке диалоговых систем, чат-ботов или голосовых помощников
- Опыт работы с платформами разработки диалоговых систем (приветствуется)

**Профессиональные знания и навыки:**

*Обязательные:*
- Понимание принципов работы NLP, NLU, ASR, TTS
- Знание основ conversational design и UX writing
- Умение проектировать диалоговые потоки (flowcharting)
- Навыки анализа данных и метрик диалогов
- Понимание принципов работы интентов и энтитетов
- Базовые знания JSON, XML для работы с конфигурациями

*Желательные:*
- Опыт работы с платформами: Dialogflow, Rasa, Just AI, Yandex SpeechKit, Sber SmartSpeech, МТС Expasoft
- Знание основ машинного обучения и NLP
- Опыт работы с системами аналитики (Google Analytics, Яндекс.Метрика, внутренние BI-системы)
- Понимание методологий A/B тестирования
- Навыки работы с регулярными выражениями
- Опыт работы в банковской сфере или финтехе

**Технические навыки:**
- Уверенный пользователь MS Office / Google Workspace
- Работа с инструментами визуализации диалогов (Draw.io, Miro, Figma)
- Умение работать с Git (базовый уровень)
- SQL (базовый уровень для анализа логов) - желательно

**Личностные качества:**
- Аналитический склад ума
- Внимание к деталям
- Креативность в формулировании фраз
- Умение работать с большими объемами данных
- Коммуникабельность и командная работа
- Клиентоориентированность
- Проактивность

### 1.5. Ключевые показатели эффективности (KPI)

- **Automation Rate** (процент автоматизированных обращений): целевой показатель 60-75%
- **Containment Rate** (процент успешно завершенных диалогов без эскалации): >70%
- **Average Conversation Length** (средняя длительность диалога): оптимизация до целевого значения
- **Intent Recognition Accuracy** (точность распознавания интентов): >85%
- **Customer Satisfaction Score** (оценка удовлетворенности после диалога): >4.0/5.0
- **Time to Deploy** (скорость внедрения новых сценариев): соблюдение сроков roadmap

### 1.6. Диапазон зарплаты (рынок РФ, 2025-2026)

**МТС Банк / Аналогичные компании:**
- **При опыте 1-2 года:** 120,000 - 180,000 ₽/мес
- **При опыте 2-3 года:** 180,000 - 220,000 ₽/мес

**Бенчмарк рынка:**
- **Сбербанк:** 130,000 - 200,000 ₽/мес (зависит от опыта и подразделения)
- **Т-Банк (Тинькофф):** 150,000 - 220,000 ₽/мес
- **Яндекс:** 160,000 - 240,000 ₽/мес
- **MTS AI:** 140,000 - 200,000 ₽/мес

### 6.5. Ключевые показатели эффективности (KPI)

**Engagement метрики:**
- **MAU (Monthly Active Users):** рост на X% QoQ
- **DAU/MAU ratio:** >25%
- **Session Frequency:** количество сессий на пользователя в месяц

**Автоматизация:**
- **Bot Resolution Rate:** >70%
- **Containment Rate:** >75%
- **Deflection Rate:** % обращений, не дошедших до операторов

**Бизнес-метрики:**
- **Cost Savings:** экономия операционных затрат
- **ROI:** положительный ROI в течение 12-18 месяцев
- **Revenue Impact:** cross-sell/up-sell через чат-бот

**Customer experience:**
- **CSAT:** >4.2/5
- **NPS текстового канала:** >55
- **Resolution Time:** среднее время решения запроса

**Operational:**
- **On-time Delivery:** >85% roadmap items вовремя
- **Feature Adoption:** >60% adoption за 3 месяца
- **Platform Uptime:** >99.5%
