# Настройка интернета на Mac через Ethernet (для GoIP-4)

Инструкция по настройке сетевого подключения Mac через USB-C Ethernet адаптер для работы с GoIP-4.

## Схема подключения

```
Интернет (WiFi или iPhone Hotspot)
   ↓
Mac M1/M2/M3
   ↓ (USB-C Ethernet адаптер)
Ethernet кабель
   ↓
GoIP-4 (порт PC или WAN)
```

Mac получает интернет по WiFi, а GoIP-4 подключен к Mac по Ethernet кабелю.

---

## Шаг 1: Проверить что Ethernet адаптер определился

1. Подключи USB-C Ethernet адаптер к Mac
2. Открой **Системные настройки** → **Сеть** (System Settings → Network)
3. В списке слева должен появиться новый интерфейс (например, `USB 10/100/1000 LAN`, `AX88179`, `Ethernet` или подобный)
4. Если адаптер не появился — попробуй переподключить или установить драйвер с сайта производителя

Проверка из терминала:

```bash
# Показать все сетевые интерфейсы
networksetup -listallnetworkservices

# Или через ifconfig — ищи интерфейс типа en0, en1 и т.д.
ifconfig
```

---

## Шаг 2: Настроить IP на Ethernet интерфейсе вручную

GoIP-4 по умолчанию имеет IP `192.168.8.1` при подключении через порт PC.
Mac нужно настроить в той же подсети.

### Через GUI (Системные настройки):

1. Открой **Системные настройки** → **Сеть**
2. Выбери Ethernet-адаптер в списке
3. Нажми **Подробнее...** (Details...)
4. Вкладка **TCP/IP**:
   - **Настроить IPv4**: Вручную (Manual)
   - **IP-адрес**: `192.168.8.10`
   - **Маска подсети**: `255.255.255.0`
   - **Маршрутизатор**: оставь пустым
5. Нажми **OK** → **Применить**

### Через терминал:

```bash
# Узнай имя Ethernet-сервиса
networksetup -listallnetworkservices

# Допустим сервис называется "USB 10/100/1000 LAN"
# Настрой статический IP:
sudo networksetup -setmanual "USB 10/100/1000 LAN" 192.168.8.10 255.255.255.0

# Проверь:
ifconfig en1  # или другой номер интерфейса
```

---

## Шаг 3: Проверить связь с GoIP-4

```bash
# Пинг GoIP
ping 192.168.8.1

# Если отвечает — подключение работает
# Открой веб-интерфейс GoIP в браузере:
# http://192.168.8.1
# Логин: admin / Пароль: admin
```

Если пинг не проходит:
- Убедись что кабель подключен в порт **PC** на GoIP (не WAN)
- Попробуй другой кабель
- Переподключи USB-C адаптер
- Проверь что GoIP включен и светодиоды горят

---

## Шаг 4: Настроить раздачу интернета (Internet Sharing)

Чтобы GoIP-4 получил интернет через Mac (для отправки SMS и т.п.):

### macOS Ventura / Sonoma / Sequoia:

1. Открой **Системные настройки** → **Основные** → **Общий доступ** (System Settings → General → Sharing)
2. Найди **Общий интернет** (Internet Sharing) — **НЕ включай пока**
3. Нажми на `(i)` рядом с Internet Sharing
4. **Общее подключение** (Share your connection from): выбери **Wi-Fi**
5. **Для компьютеров, использующих** (To computers using): отметь галочкой **USB 10/100/1000 LAN** (или как называется твой Ethernet)
6. Включи переключатель **Internet Sharing**
7. Подтверди в диалоговом окне

**Важно**: После включения Internet Sharing, Mac автоматически назначит IP для Ethernet интерфейса (обычно `192.168.2.1`). GoIP получит IP по DHCP.

### Через терминал (альтернатива):

```bash
# Проверить статус
sudo defaults read /Library/Preferences/SystemConfiguration/com.apple.nat

# Включить Internet Sharing из терминала не рекомендуется — лучше через GUI
```

## Шаг 5: Узнать новый IP GoIP после Internet Sharing

После включения Internet Sharing, IP-адреса изменятся:
- Mac Ethernet: `192.168.2.1` (раздает DHCP)
- GoIP: получит адрес вроде `192.168.2.x`

Чтобы узнать IP GoIP:

```bash
# Вариант 1: Посмотреть таблицу ARP
arp -a | grep 192.168.2

# Вариант 2: Просканировать подсеть
# Установи nmap если нет:
brew install nmap
nmap -sn 192.168.2.0/24

# Вариант 3: Попробовать типичные адреса
ping 192.168.2.2
ping 192.168.2.3
```

Откройте найденный IP в браузере для доступа к веб-интерфейсу GoIP.

## Шаг 6: Обновить конфигурацию проекта

После определения IP-адресов обновите конфиги:

### 1. Узнать IP Mac:

```bash
# IP на WiFi (интернет)
ipconfig getifaddr en0

# IP на Ethernet (к GoIP)
ipconfig getifaddr en1  # или другой номер

# Показать все IP
ifconfig | grep "inet " | grep -v 127.0.0.1
```

### 2. Обновить pjsip.conf если нужно

Если IP GoIP изменился, обновите `docker/asterisk/etc/pjsip.conf`.

### 3. Перезапустить Docker

```bash
cd ~/123  # или путь к проекту
docker compose down
docker compose up -d
```

## Два варианта подключения

### Вариант A: Прямое подключение (без интернета для GoIP)

Используйте если GoIP не нужен доступ в интернет (только SIP и звонки).

```
WiFi → Mac (192.168.8.10) ←Ethernet→ GoIP-4 (192.168.8.1)
```

- Mac Ethernet IP: `192.168.8.10`
- GoIP IP: `192.168.8.1`
- Internet Sharing: ВЫКЛЮЧЕН
- GoIP подключать в порт **PC**

### Вариант B: С раздачей интернета (Internet Sharing)

Используйте если GoIP нужен интернет (для SMS через HTTP и т.п.).

```
WiFi → Mac (192.168.2.1) ←Ethernet→ GoIP-4 (192.168.2.x, DHCP)
```

- Mac Ethernet IP: `192.168.2.1` (автоматически)
- GoIP IP: `192.168.2.x` (получит по DHCP)
- Internet Sharing: ВКЛЮЧЕН
- GoIP подключать в порт **WAN**

## Частые проблемы

### Ethernet адаптер не появляется в настройках
- Переподключите USB-C адаптер
- Попробуйте другой USB-C порт
- Некоторые адаптеры требуют драйвер — скачайте с сайта производителя
- Перезагрузите Mac

### Пинг до GoIP не проходит
- Проверьте что кабель подключен в правильный порт GoIP (**PC** для прямого, **WAN** для Internet Sharing)
- Убедитесь что IP Mac и GoIP в одной подсети
- Отключите файрвол Mac временно: Системные настройки → Сеть → Брандмауэр → Выключить
- Попробуйте другой Ethernet кабель

### WiFi отключается после включения Internet Sharing
- Это нормальное поведение на некоторых версиях macOS
- Убедитесь что WiFi подключен к сети ДО включения Internet Sharing
- Если WiFi отвалился — выключите Internet Sharing, подключите WiFi заново, затем снова включите Sharing

### Docker контейнеры не видят GoIP
- Asterisk работает в `network_mode: host`, поэтому он видит все интерфейсы Mac напрямую
- Проверьте: `docker exec -it phone-asterisk ping 192.168.8.1` (или актуальный IP GoIP)
- Если не пингуется — проблема в сетевых настройках Mac

### Internet Sharing назначает IP не `192.168.2.x`
- macOS может использовать другую подсеть (`10.0.x.x` или `192.168.137.x`)
- Используйте `ifconfig` чтобы узнать какой IP назначен на Ethernet после включения Sharing
- Обновите конфигурацию проекта соответственно

## Быстрая диагностика

Запустите эти команды для проверки состояния сети:

```bash
# 1. Список сетевых сервисов
networksetup -listallnetworkservices

# 2. Все IP адреса
ifconfig | grep "inet " | grep -v 127.0.0.1

# 3. Пинг GoIP (прямое подключение)
ping -c 3 192.168.8.1

# 4. Пинг GoIP (Internet Sharing)
ping -c 3 192.168.2.2

# 5. Таблица ARP (найти GoIP)
arp -a

# 6. Проверить что Docker работает
docker compose ps

# 7. Проверить Asterisk
docker exec phone-asterisk asterisk -rx "pjsip show endpoints"
```
